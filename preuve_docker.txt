2. MODE D'EMPLOI
   L'image contient l'application, pas les données. Les résultats MapReduce (fichiers part-*)
   sont fournis au lancement par un volume monté dans /app/resultats (variable DOSSIER_RESULTATS).

   a) Récupérer les résultats MapReduce (dossier resultats/ du dépôt) :
      git clone https://github.com/lezoul/hadoop-mapreduce-ventes-multimagasins.git
      cd hadoop-mapreduce-ventes-multimagasins

   b) Télécharger l'image :
      docker pull yacinelezoul/dashboard-ventes:1.0

   c) Lancer le conteneur
      Windows (PowerShell) :
        docker run -d --name dashboard-ventes -p 8501:8501 -v "${PWD}\resultats:/app/resultats:ro" yacinelezoul/dashboard-ventes:1.0
      Linux / macOS :
        docker run -d --name dashboard-ventes -p 8501:8501 -v "$(pwd)/resultats:/app/resultats:ro" yacinelezoul/dashboard-ventes:1.0

   d) Ouvrir http://localhost:8501
      L'onglet « Provenance et contrôles » doit afficher le dossier /app/resultats et le bandeau vert
      « Les 5 jobs donnent le même total ».

   e) Arrêter et supprimer le conteneur :
      docker rm -f dashboard-ventes

   Paramètres :
      -p 8501:8501               port de Streamlit (conteneur -> machine hôte)
      -v <resultats>:/app/resultats:ro   dossier des sorties MapReduce, monté en lecture seule
      Structure attendue du volume : ca_detail/, ca_mois/, ca_magasin/, ca_categorie/, ca_produit/,
      chacun contenant un ou plusieurs fichiers part-*
